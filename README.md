# Cannodles

Landing page de uma loja de canudos fictícia feita em HTML, CSS, Java Script e React.jsx

## Instalação

1. Clone o repositório:
   ```bash
   git clone https://github.com/isabelisimek/Canoodles
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o projeto:
   ```bash
   npm run dev
   ```
